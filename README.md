# HTTP download speed meter

Небольшое тестовое для AD Robot. Python 3.9+, только стандартная библиотека.

## Запуск

```bash
python3 speedtest.py 'https://your-server.example/large-image.jpg'
python3 speedtest.py 'https://your-server.example/large-image.jpg' --timeout 15
```

Замените пример на прямой HTTP(S)-адрес реального большого файла. Скрипт скачает его **10 раз последовательно**, не сохраняя на диск и не удерживая целиком в памяти. Учитывайте расход трафика: для файла 20 MB будет загружено примерно 200 MB.

Для каждого запроса выводятся реально прочитанные байты и длительность до окончания скачивания. Затем выводятся среднее время запроса, суммарный объём, общее время и скорость:

- среднее время = сумма длительностей / 10;
- скорость = все скачанные байты / сумму длительностей;
- MB/s использует десятичные мегабайты (1 MB = 1 000 000 байт);
- Mbit/s = MB/s × 8.

Например, 20 000 000 байт за суммарные 10 секунд дают 2 MB/s, или 16 Mbit/s. Это пример расчёта, а не результат реального замера.

Время измеряется монотонным `perf_counter()`, начиная перед открытием соединения и заканчивая после чтения тела. Вывод в консоль не входит в расчёт скорости. Читаем блоками по 64 KiB, не доверяем одному лишь Content-Length. Просим сервер не сжимать ответ и перепроверять кеш, но сервер может не выполнить эти заголовки.

При сетевой ошибке, таймауте или HTTP-ошибке скрипт завершится с кодом 1 и не выдаст неполный запуск за итоговый замер. `--timeout` ограничивает ожидание сетевых операций, а не полное время скачивания. Ctrl+C завершает работу с кодом 130.

Измеряется скорость получения тела HTTP-ответа от выбранного сервера, включая задержки подключения. Результат зависит от сервера, маршрута и размера файла, поэтому не равен гарантированной пропускной способности интернет-канала. Заголовки HTTP и служебный сетевой трафик не входят в объём.

## Проверки

```bash
python3 -m unittest -v
```

Тесты поднимают локальный HTTP-сервер и проверяют ровно 10 последовательных скачиваний, подсчёт фактически прочитанных байтов, обработку HTTP-ошибки, формулу средней скорости и проверку входных аргументов. Интернет для тестов не требуется.
